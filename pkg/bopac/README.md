bopac
=====


Presentation
------------

*bopac* is a CLI for creating *boilerplates*. It spins a Web-UI to configure the *boilerplates*.


Requirements
------------

- [node](https://nodejs.org) > 24.0.0
- [npm](https://docs.npmjs.com/cli) > 12.0.0


Installation
------------

```bash
npm i -D bopac
```


Usage
-----

```bash
npx bopac
npx bopac --help
```


Usage without installation
--------------------------

```bash
npx bopac
npx --package=bopac bopac
npx --package=bopac bopac --help
```


Development
-----------

```bash
git clone https://github.com/charlyoleg2/bopa_mono
cd bopa_mono
npm install
npm run ci
npm -w bopac run run
```
